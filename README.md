# 🐍 لعبة الثعبان Snake Game

## الوصف
لعبة ثعبان كلاسيكية مصنوعة بـ Python و Pygame

## المتطلبات
- Python 3.8+
- Pygame

## التثبيت
```bash
pip install -r requirements.txt
```

## كيفية اللعب
```bash
python snake_game.py
```

## التحكم
- **الأسهم**: تحريك الثعبان (أعلى، أسفل، يسار، يمين)
- **الهدف**: جمع الطعم الأحمر وتجنب الجدران والاصطدام بالنفس
- **النقاط**: كل طعمة = 10 نقاط
